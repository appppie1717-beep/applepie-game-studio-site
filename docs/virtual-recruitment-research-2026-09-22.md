## 에르시안에 적용할 결론

### 공개 홈페이지는 짧은 모집 안내로 구성

이번 개편은 상세 FAQ를 모두 나열하는 방식보다, 에르시안의 첫 크리에이터를 모집한다는 사실과 활동 방향을 빠르게 전달하는 데 초점을 둔다. 상단에는 모집 정체성, 짧은 소개, 지원 행동을 배치한다. 이어서 실제 협업·지원 범위와 지원 준비 안내만 읽기 쉽게 보여준다.

홈페이지의 조건과 Google Forms의 문항은 서로 맞아야 한다. 폼에서 묻지 않는 경력·포트폴리오·자기소개를 홈페이지에서 필수 준비물처럼 요구하지 않는다. 별도 직무나 다수의 전형, 긴 FAQ, 검증되지 않은 실적 수치는 추가하지 않는다.

### 지원서는 확정된 문항으로 구성

Google Forms는 닉네임, 생년월일, 성별, 이메일, 활동 가능 시간, 현재 소속 여부, 음성 제출의 기본 7개 항목을 필수로 구성한다. 여기에 비필수 채널 링크 문항 1개를 더해 정보 입력 문항은 총 8개다. 채널 문항 제목은 “방송하던 채널이 있나요?”, 설명은 “채널 링크를 남겨주세요.”이며, 제목에 별표나 선택 여부 표기를 붙이지 않는다. 성별 선택은 사용자 결정에 따른 남자·여자다. 개인정보 관련 동의 2개는 정보 입력 질문과 구분해 유지한다.

음성은 **시청자 5명이 있는 방송을 가정한 3~5분 자유 음성**으로 안내한다. 지원자가 무엇을 준비해야 하는지 알 수 있도록 길이와 상황을 짧게 설명하며, 노래·편집된 포트폴리오·추가 경력 자료를 필수로 늘리지 않는다. 파일 업로드에 필요한 Google 로그인도 제출 전에 알린다.

### 세부 활동 조건은 지원서에서 확인

정산 비율과 IP 세부 조건은 공개 홈페이지·검색용 설명·이 비교 문서에 싣지 않는다. 사용자가 확정한 활동 조건은 Google Forms의 사전 안내에서 확인할 수 있게 배치하고, 최종 협업 결정 전에 설명과 합의가 이루어지도록 연결한다. 경쟁사가 자세히 공개하지 않는다는 이유가 아니라, 이번 작업에서 사용자가 정한 공개 범위를 따른다.

## 디자인에 옮길 원칙

비교에서 가져올 것은 정보의 우선순위와 지원 결정을 돕는 방식이다. 짧은 모집 포스터처럼 정체성·상태·지원 행동이 먼저 보이고, 구체적인 설명은 읽기 좋은 본문으로 이어지게 한다. 카드 개수를 맞추기 위해 항목을 늘리거나 장식적 배경·과도한 모션을 추가하지 않는다.

캐릭터·로고·이미지·카피는 각 소속사의 자산이므로 복제하지 않는다. 구현의 색상·서체·여백·반응형·접근성·모션 적합성은 별도의 실제 브라우저 검수에서 확인해야 한다.
